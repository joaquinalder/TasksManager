# Tasks API

API REST de TasksManager, escrita en NestJS y TypeScript. Usa Prisma para acceder a PostgreSQL.

La API expone autenticación, proyectos y tareas bajo `/api/v1`. Swagger está en `/docs`. Los proyectos y tareas nuevos quedan asociados al usuario autenticado.

Consultá el [README de TasksManager](../README.md) para iniciar los servicios, aplicar migraciones y ejecutar las pruebas.
